# Lap record tracker

This software can be used to track and store data about racing simulators. 
You can track lap times, which car was used, what were the weather conditions 
and what assists and other settings were in effect. You can also choose the simulator/racing game 
to compare between the different physics models used. This allows you to better understand 
how fast you truly are, since you can easily compare the lap times on the same track across multiple games. 
All this can be managed through a graphical user interface.
